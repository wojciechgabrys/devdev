# Crashed

Sharpened by this feature: a signal also counts, not only a non-zero exit code. `GLOSSARY.md` was amended to match the spec. A Project is Crashed if any of its Commands is. Stop on a Crashed Command sets it to Stopped without a notification.

_Avoid_: failed, errored, dead
