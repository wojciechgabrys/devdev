# Discovery-made Command

Commands confirmed in the Discovery checklist are added with `madeByDiscovery: true`. Rescan may offer to remove only these, and only when Discovery no longer proposes them. A hand edit clears the mark, so the Command then belongs to the user.

_Avoid_: auto command, detected command
